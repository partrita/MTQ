Note질문
  • 파이썬 프로그램을 어떻게 실행할 수 있나요?

앞으로 이 워크샵에서는 파이썬을 실행하기 위해 JupyterLab 위에서 돌아가는 [Jupyter Notebooks][jupyter]를 사용한다. Jupyter 노트북은 데이터 과학과 시각화 분야에서 흔히 쓰이는데, 파이썬 코드를 대화형으로 실행하고 결과를 바로 확인하며 공유하기도 편리하다.

코드를 편집하고, 관리하며 실행하는 다른 방법들도 존재한다. 소프트웨어 개발자들은 종종 파이썬 프로그램을 만들고 편집할 때 PyCharm이나 Visual Studio Code 같은 통합 개발 환경(IDE), 혹은 Vim이나 Emacs 같은 텍스트 편집기를 사용한다. 파이썬 프로그램을 편집하고 저장한 뒤에는 IDE 내부나 커맨드 라인에서 직접 해당 프로그램을 실행할 수 있다. 반면, Jupyter 노트북은 노트북 안에서 파이썬 코드를 실행하고 그 결과를 즉시 볼 수 있게 해준다.

JupyterLab은 그 밖에도 다음과 같은 유용한 기능을 갖추고 있다:

  • 코드 블록을 쉽게 타이핑, 편집, 복사, 붙여넣기 할 수 있다.
  • 탭 자동 완성(Tab complete)으로 사용 중인 객체의 이름에 쉽게 접근하고 더 자세히 알아볼 수 있다.
  • 코드에 링크, 크기가 다른 텍스트, 글머리 기호 등을 추가하여 여러분과 협업자들이 더 쉽게 코드를 이해할 수 있도록 도와준다.
  • 그림을 생성하는 코드 바로 옆에 출력된 그림을 함께 보여주어, 데이터 분석의 전체 흐름을 한눈에 파악할 수 있게 해준다.

각 노트북은 코드가 적힌 셀, 텍스트가 적힌 셀, 이미지가 들어 있는 셀 하나 이상으로 이루어진다.

JupyterLab 시작하기

JupyterLab은 [Project Jupyter][jupyter]에서 만든 웹 사용자 인터페이스를 갖춘 애플리케이션 서버로, 여러 문서와 활동(Jupyter 노트북, 텍스트 편집기, 터미널, 심지어 커스텀 컴포넌트까지)을 유연하고 통합된, 확장 가능한 방식으로 다룰 수 있게 해준다. JupyterLab은 비교적 최신 브라우저(이상적으로는 Chrome, Safari, 또는 Firefox의 최신 버전)가 필요하다. Internet Explorer 9 이하 버전을 비롯한 예전 브라우저는 지원하지 않는다.

JupyterLab은 Anaconda 파이썬 배포판의 일부로 포함되어 있다. Anaconda 배포판을 아직 설치하지 않았다면 설정 안내의 설치 지침을 참고하라.

이번 학습에서는 JupyterLab 서버를 로컬 기기에서 직접 실행할 것이므로, Anaconda와 JupyterLab을 다운로드하고 설치하기 위한 최초 연결을 제외하고는 인터넷 연결이 필요하지 않는다.

  • 여러분의 기기에서 JupyterLab 서버를 시작한다.
  • 웹 브라우저를 사용하여 JupyterLab 서버에 연결되는 특수한 localhost URL을 연다.
  • JupyterLab 서버가 작업을 수행하고 웹 브라우저가 결과를 렌더링(화면에 표시)한다.
  • 브라우저에 코드를 입력하고 JupyterLab 서버가 코드 실행을 마치면 그 결과를 확인한다.
NoteJupyterLab? Jupyter notebooks와는 어떻게 다른가요?

JupyterLab은 Jupyter Notebook의 진화된 다음 단계인다. Jupyter 노트북을 사용해 본 경험이 있다면, JupyterLab에서도 무엇을 기대할 수 있는지 잘 파악할 수 있을 것이다.

JupyterLab과 Jupyter 노트북 사용자 인터페이스 간의 유사점과 차이점에 대해 더 자세히 알고 싶은 기존 노트북 사용자들은 JupyterLab 인터페이스 문서에서 추가 정보를 확인할 수 있다.

JupyterLab 실행하기

JupyterLab 서버는 커맨드 라인에서 시작할 수도 있고 Anaconda Navigator라는 애플리케이션으로도 시작할 수 있다. Anaconda Navigator는 Anaconda 파이썬 배포판에 포함되어 있다.

macOS - 커맨드 라인(Command Line)

JupyterLab 서버를 시작하려면 터미널(Terminal)로 커맨드 라인에 접근해야 한다. Mac에서 터미널을 여는 두 가지 방법이 있다.

  1. 응용 프로그램(Applications) 폴더에서 유틸리티(Utilities)를 열고 터미널(Terminal)을 더블 클릭한다.
  2. Command + spacebar를 눌러 Spotlight를 실행한다. Terminal을 입력한 다음 결과물을 더블 클릭하거나 Enter를 누른다.

터미널을 실행한 뒤, JupyterLab 서버를 실행하는 명령어를 입력한다.

$ jupyter lab

Windows 사용자 - 커맨드 라인

JupyterLab 서버를 시작하려면 Anaconda Prompt에 접근해야 한다.

Windows 로고 키를 누르고 Anaconda Prompt를 검색한 뒤 결과를 클릭하거나 엔터를 누른다.

Anaconda Prompt가 실행되면 다음 명령어를 입력한다:

$ jupyter lab

JupyterLab 인터페이스

JupyterLab에는 기존 통합 개발 환경(IDE)에서 보던 여러 기능이 있지만 상호작용적이고 탐색적인 컴퓨팅(exploratory computing)에 맞춰 유연한 구성 요소를 조합하는 데 중점을 두고 있다.

JupyterLab 인터페이스는 주요 메뉴 바(Menu Bar), 접을 수 있는 좌측 사이드 바(Left Side Bar), 그리고 문서와 활동을 담는 탭이 모인 메인 작업 공간(Main Work Area)으로 이루어져 있다.

메뉴 바 (Menu Bar)

화면 맨 위의 메뉴 바에는 JupyterLab에서 쓸 수 있는 동작(그리고 적용 가능한 경우 단축키)이 최상위 메뉴로 모여 있다. 기본적으로 다음과 같은 메뉴가 포함되어 있다.

  • File(파일): 파일 및 복사본에 관한 동작들 (예: New(새로 만들기), Open(열기), Close(닫기), Save(저장) 등). File 메뉴에는 JupyterLab 서버를 정지시키기 위한 Shut Down(종료) 동작도 포함되어 있다.
  • Edit(편집): 문서 편집 및 기타 작업에 관한 동작들 (예: Undo(실행 취소), Cut(잘라내기), Copy(복사), Paste(붙여넣기) 등).
  • View(보기): JupyterLab의 형태와 외관을 변경하는 동작들.
  • Run(실행): 노트북이나 코드 콘솔과 같은 다양한 활동 구역 안에서 코드를 실행하기 위한 동작들.
  • Kernel(커널): 커널을 관리하기 위한 동작들. Jupyter 커널에 대해서는 아래에서 자세히 설명할 예정이다.
  • Tabs(탭): 메인 작업 공간에 열려있는 문서와 활동들의 목록.
  • Settings(설정): 이 메뉴에서 일반적인 JupyterLab 설정을 조정한다. 드롭다운 메뉴의 Advanced Settings Editor(고급 설정 편집기) 옵션으로 설정과 구성 옵션을 더 정교하게 제어할 수 있다.
  • Help(도움말): JupyterLab과 커널에 대한 여러 도움말 링크 모음집.
Note커널 (Kernels)

JupyterLab 공식 문서는 커널을 “서버가 코드를 다른 프로그래밍 언어 및 환경에서 실행하기 위해 별도로 시작한 프로세스”로 정의한다. Jupyter 노트북을 열면, 코드를 실행할 일종의 프로세스인 커널이 시작된다. 이번 학습에서는 인터랙티브하게 Python 3 코드를 실행할 수 있도록 하는 Jupyter의 ipython 커널을 사용할 것이다.

Jupyter용 프로그래밍 언어 커널을 사용하면 R, Java, Julia, Ruby, JavaScript, Fortran 같은 다른 프로그래밍 언어로 작성된 코드도 똑같은 JupyterLab 인터페이스에서 작성하고 실행할 수 있다.

NoteCode vs. Text

Jupyter 노트북 환경에서는 코드(Code)와 텍스트(Text)가 각각의 칸으로 나뉘어 있는 것을 볼 수 있다. 이렇게 개별적으로 분리된 각각의 칸을 ’셀(cell)’이라고 부른다. 보통 프로그래밍 분야에서 “코드”라고 하면 “파이썬과 같은 프로그래밍 언어로 작성된 명령어 모음”을 의미한다. 즉 노트북 환경에서 “코드 셀(Code cell)”이란 컴퓨터가 이해하고 실행할 수 있는 명령어 구문이 들어가는 공간이며 “텍스트 셀(Text cell)”은 사람이 읽고 쓸 수 있는 일반적인 문서 용도로 사용된다.

Notebook의 ‘명령(Command)’ 모드와 ‘편집(Edit)’ 모드

  • 키보드의 Esc 키와 Return(엔터) 키를 번갈아 누르면 선택된 셀의 테두리 색상이 파란색과 회색으로 번갈아 바뀌는 것을 확인할 수 있다.
  • 이는 노트북의 두 가지 조작 방식인 명령 모드(Command, 테두리 회색) 와 편집 모드(Edit, 테두리 파란색) 를 의미한다.
  • ’명령 모드’는 노트북 레벨에서 셀 전체의 구조 조작을 담당하며 ’편집 모드’는 특정 셀 안에 있는 내용을 직접 수정할 수 있도록 해준다.
  • 외곽선이 회색인 명령 모드에서 사용할 수 있는 주요 단축키는 다음과 같다:
    • b 키를 누르면 현재 셀 바로 아래(Below)에 새로운 셀을 삽입한다.
    • a 키를 누르면 현재 셀 바로 위(Above)에 새로운 셀을 삽입한다.
    • x 키를 누르면 현재 선택된 셀을 삭제할 수 있다.
    • z 키를 누르면 최근의 셀 조작 작업(삭제, 복사, 생성 등)을 실행 취소(되돌리기)한다.

각종 수학 수식 공식(Equations) 표현

기본 마크다운 문법만으로는 복잡한 수학 방정식(Equations)을 책처럼 예쁘게 표시(Render)하기 어렵지만 특수한 형태의 표현식으로 노트북 환경에서는 이런 수식 표시를 지원한다. 신규 마크다운 셀을 하나 생성하고 다음 내용을 입력하거나 복사 후 붙여넣어 보라:

$\sum_{i=1}^{N} 2^{-i} \approx 1$

화면에 어떻게 표시되나요? 밑줄(_) 기호, 해시 꺽쇠 기호(^), 달러 마크 기호($)가 렌더링 엔진에서 각각 어떤 역할을 하는지 고민해 보라.

Caution해답

해답

이 노트북은 입력된 공식을 LaTeX(라텍스) 수식 규칙에 맞춰 렌더링한다. 앞뒤에 붙은 달러($) 기호는 이 구역의 기호들이 일반 텍스트가 아니라 LaTeX 형식의 특수 수식임을 시스템 엔진에 알려준다. LaTeX 기호 문법에 낯선 분들은 참고하라: 밑줄(_) 기호는 아래 첨자(subscripts)로 기능하고 해시 기호(^)는 위로 솟은 제곱수나 윗 첨자 형태(superscripts)를 표기한다. 중괄호 { 와 }는 묶음 용도로 쓰여, 안쪽의 i=1을 통째로 하나로 묶는다. 덕분에 밑부분 전체가 아래 첨자로 들어가고 오른쪽 문자 N과 분리되어 보이다. 오른쪽의 {-i} 부분도 중괄호로 분리되어 숫자 2 위에 놓이는 윗 첨자로 기능한다. 마지막으로 \sum이나 \approx 같은 문구는 라텍스 언어 안에서 약속된 특수 명령어이다. 합을 뜻하는 큰 수학 기호 “시그마(sum over)”, “대략 근사하는(approximate)” 의미의 특수 기호로 화면에 예쁘게 인쇄해 준다!

변수를 사용하여 값을 저장한다.

  • 변수(Variables)는 값에 붙이는 이름이다.
  • 변수명 규칙:
    • 문자, 숫자, 밑줄(_)만 포함할 수 있다.
    • 숫자로 시작할 수 없다.
    • 대소문자를 구분한다 (age, Age, AGE는 모두 다른 변수이다).
  • 변수 이름은 코드의 의도를 파악할 수 있도록 의미 있게 짓는 것이 좋다.
  • 파이썬에서 = 기호는 오른쪽에 있는 값을 왼쪽에 있는 변수에 할당(대입)한다는 의미다.
age = 42
first_name = 'Ahmed'

print를 사용하여 값을 출력한다.

  • print() 함수는 전달받은 값을 화면에 출력한다.
  • 함수를 실행하는 것을 호출(call)한다고 하며 괄호 안에 전달하는 값을 인수(arguments)라고 한다.
print(first_name, 'is', age, 'years old')
  • print는 여러 인수를 출력할 때 사이에 공백을 자동으로 추가하며 출력이 끝나면 줄을 바꾼다.

변수는 사용하기 전에 정의되어야 한다.

  • 정의되지 않은 변수를 사용하거나 이름을 잘못 입력하면 파이썬은 오류를 발생시킨다.
# print(last_name)  # NameError 발생
NoteJupyter Notebook의 실행 순서

Jupyter Notebook에서는 셀의 위치보다 실행된 순서가 중요하다. 이전에 실행한 셀에서 정의된 변수는 메모리에 유지되어 다른 셀에서도 사용할 수 있다. 실행 순서가 꼬여 혼란스러울 때는 Kernel -> Restart & Run All을 사용하여 모든 변수를 초기화하고 처음부터 순서대로 실행해 보는 것이 좋다.

변수를 사용한 계산

  • 변수를 마치 실제 값처럼 계산식에 사용할 수 있다.
age = age + 3
print('Age in three years:', age)

인덱스(Index)를 이용한 문자 추출

  • 문자열 내의 각 문자는 고유한 위치 번호를 가지며 이를 인덱스(index)라고 한다.
  • 인덱스는 0부터 시작한다.
  • 대괄호 [] 안에 인덱스 번호를 넣어 특정 위치의 문자 하나를 가져올 수 있다.
atom_name = 'helium'
print(atom_name[0])

슬라이스(Slice)를 이용한 부분 문자열 추출

  • 문자열의 일부분을 추출한 것을 부분 문자열(substring)이라고 한다.
  • [start:stop] 표기법을 사용하여 슬라이싱한다. start 인덱스부터 stop 인덱스 직전까지의 문자를 가져온다.
  • 슬라이싱을 해도 원본 문자열은 변하지 않으며 지정된 범위의 복사본을 반환한다.
atom_name = 'sodium'
print(atom_name[0:3])  # 인덱스 0, 1, 2에 해당하는 'sod' 추출

문자열 길이 확인: len

  • len() 함수는 문자열에 포함된 문자의 총 개수를 반환한다.
print(len('helium'))

의미 있는 변수명 사용하기

  • 파이썬 문법만 지킨다면 어떤 이름이든 가능하지만 자신과 동료가 코드를 쉽게 이해할 수 있도록 명확한 이름을 사용해야 한다.

flabadab = 42
# 좋은 예
age = 42

제3장: 데이터 타입과 타입 변환

Tip학습 목표
  • 정수와 부동소수점 숫자의 주요 차이점을 설명한다.
  • 숫자와 문자열의 차이점을 이해한다.
  • 내장 함수를 사용하여 데이터 타입을 변환한다.
Note질문
  • 파이썬은 어떤 종류의 데이터를 저장하는가?
  • 한 데이터 타입을 다른 타입으로 어떻게 변환하는가?

모든 값에는 타입(Type)이 있다.

  • 파이썬의 모든 값은 특정한 데이터 타입을 가진다.
  • 정수 (int): 3, -512와 같이 소수점이 없는 숫자이다.
  • 부동소수점 숫자 (float): 3.14, -2.5와 같이 소수점이 포함된 숫자이다.
  • 문자열 (str): 텍스트 데이터이다. 작은따옴표나 큰따옴표로 감싸서 작성한다.

type() 함수를 사용한 타입 확인

  • 값이나 변수의 데이터 타입을 알고 싶을 때는 type() 함수를 사용한다.
print(type(52))
fitness = 'average'
print(type(fitness))

타입에 따른 연산의 제한

  • 데이터 타입에 따라 수행할 수 있는 작업이 달라진다.
print(5 - 3)
# print('hello' - 'h')  # TypeError 발생: 문자열 간의 뺄셈은 지원하지 않음

문자열의 특수 연산

  • + 연산자: 두 문자열을 하나로 이어 붙이다(concatenation).
  • * 연산자: 문자열을 정수 횟수만큼 반복한다.
full_name = 'Ahmed' + ' ' + 'Walsh'
print(full_name)
print('=' * 10)

문자열의 길이와 숫자 데이터

  • len() 함수는 문자열의 길이를 반환하지만 숫자 데이터(int, float)에는 적용할 수 없다.
print(len(full_name))
# print(len(52))  # TypeError 발생

데이터 타입 변환

  • 서로 다른 타입(예: 숫자와 문자열)을 직접 더하면 오류가 발생한다.
  • str(), int(), float() 함수를 사용하여 명시적으로 타입을 변환해야 한다.
print(1 + int('2'))
print(str(1) + '2')

정수와 부동소수점 숫자의 혼용

  • 정수형과 부동소수점형을 함께 계산하면, 파이썬은 결과를 자동으로 부동소수점형으로 변환한다.
print('half is', 1 / 2.0)
print('three squared is', 3.0 ** 2)

제4장: 내장 함수와 도움말

Tip학습 목표
  • 함수의 목적을 설명할 수 있다.
  • 파이썬 내장 함수를 호출하는 방법을 익힌다.
  • 함수 호출을 중첩하여 사용하는 방법을 이해한다.
  • 도움말(help) 기능을 사용하여 내장 함수의 문서를 조회한다.
  • SyntaxError와 NameError의 차이점을 파악하고 해결 방법을 익힌다.
Note질문
  • 내장 함수는 어떻게 사용하는가?
  • 함수의 동작 방식을 어떻게 확인할 수 있나요?
  • 프로그래밍 중에 발생하는 오류에는 어떤 것들이 있나요?

주석(Comments)을 활용한 코드 설명

# 이 문장은 파이썬에 의해 실행되지 않습니다.
adjustment = 0.5   # '#' 기호 뒤의 내용은 실행 시 무시됩니다.

함수의 인수(Arguments)

  • 함수에 전달하는 값을 인수(Argument)라고 한다.
  • len 함수는 정확히 하나의 인수를 받는다.
  • int, str, float 함수는 데이터의 형식을 변환하여 새로운 값을 반환한다.
  • print 함수는 인수가 없어도 실행되며 여러 개의 인수를 동시에 받을 수도 있다.
  • 인수가 없더라도 함수를 호출할 때는 반드시 소괄호(())를 붙여야 파이썬이 이를 함수 호출로 인식한다.
print('before')
print()
print('after')

함수의 반환값(Return Value)

  • 모든 함수는 실행 후 결과를 반환한다.
  • 명시적인 반환값이 없는 함수는 파이썬의 특수 객체인 None을 반환한다. None은 ’값이 없음’을 나타낸다.
result = print('example')
print('result of print is', result)

주요 내장 함수: max, min, round

  • max: 주어진 값들 중 최댓값을 찾는다.
  • min: 주어진 값들 중 최솟값을 찾는다.
  • 숫자뿐만 아니라 문자열(사전순 기준)에서도 작동한다.
print(max(1, 2, 3))
print(min('a', 'A', '0'))

인수의 타입 제한

  • max와 min은 최소 하나 이상의 인수가 필요하며 서로 비교 가능한 타입의 인수가 전달되어야 한다. 그렇지 않으면 오류가 발생한다.
# print(max(1, 'a'))  # TypeError 발생

인수의 기본값(Default values)

  • 일부 함수는 인수를 생략할 경우 사용하는 기본값이 정해져 있다.
  • 예를 들어 round 함수는 두 번째 인수를 생략하면 소수점 첫째 자리에서 반올림하여 정수를 반환한다.
print(round(3.712))
print(round(3.712, 1))

메서드(Methods)

  • 특정 객체에 속해 있는 함수를 메서드(Method)라고 부른다.
  • 객체 이름 뒤에 점(.)을 찍고 호출한다.
my_string = 'Hello world!'
print(len(my_string))           # 일반 함수 호출
print(my_string.swapcase())     # 메서드 호출
  • 여러 메서드를 이어서 호출하는 메서드 체이닝(Method Chaining)도 가능하다.
print(my_string.upper().isupper())

도움말 확인하기: help

  • help() 함수를 사용하여 내장 함수의 상세 문서를 확인할 수 있다.
help(round)
  • Jupyter Notebook에서는 함수 이름 뒤에 ?를 붙여 실행하거나, 함수 이름에서 Shift + Tab을 눌러 도움말을 볼 수 있다.

구문 오류 (Syntax Error)

  • 파이썬 문법에 맞지 않게 코드를 작성했을 때 발생하며 이 경우 코드는 실행되지 않는다.
# name = 'Feng  # 닫는 따옴표 누락
# age == 52     # 할당 시 등호 중복 (비교 연산자로 오해될 수 있음)

실행 오류 (Runtime Error)

  • 문법은 맞지만 실행 도중에 발생하는 오류이다. 대표적으로 정의되지 않은 변수를 사용할 때 발생하는 NameError가 있다.
age = 53
# remaining = 100 - aege  # 오타로 인한 NameError 발생

코딩 문제 해결을 위한 도움 받기

코딩 중에 오류가 발생하거나 막막할 때는 다음과 같은 방법을 쓸 수 있다.

  1. 검색 엔진 활용: 에러 메시지의 마지막 줄을 복사하여 검색해 보라. Stack Overflow와 같은 커뮤니티에서 많은 도움을 얻을 수 있다. 단, 해결책을 이해하지 못한 채 복사하여 붙여넣는 것은 피해야 한다.
  2. 동료에게 질문하기: 문제를 명확히 정리하여 주변에 조언을 구하라.
  3. 고무 오리 디버깅: 코드의 작동 방식을 소리 내어 설명하다 보면 스스로 해결책을 찾는 경우가 많다.

생성형 AI 활용 가이드

최근에는 ChatGPT와 같은 생성형 AI를 활용하여 코딩 도움을 받는 경우가 많아지고 있다. 에러 메시지를 입력하면 즉각적인 해결책을 제안받을 수 있어 편리하지만 다음과 같은 주의사항을 숙지해야 한다.

  • 작동 원리의 이해: 생성형 AI는 실제 추론을 하는 것이 아니라, 학습된 방대한 데이터를 바탕으로 확률적으로 가장 적절해 보이는 답변을 생성한다. 따라서 답변이 논리적으로 완벽하지 않거나 틀린 정보를 정답처럼 제시할 수 있다(환각 현상).
  • 검증의 필요성: AI가 제공한 코드는 반드시 사용자가 직접 검토하고 테스트해야 한다. 기초 지식이 부족한 상태에서 AI에만 의존하면 문제 해결 능력을 기르기 어려워진다.
  • 윤리적 및 환경적 고려: AI 모델 학습과 운영에는 막대한 전력과 자원이 소비된다. 또한 데이터 저작권이나 투명성 문제에 대해서도 지속적인 논의가 이루어지고 있다.

학습 과정에서의 권장 사항: 이 워크숍 기간 동안은 가급적 AI 도구에 의존하기보다 직접 문제를 해결해 보시길 권장한다. 1. 입문 단계의 오류는 웹 검색만으로도 충분히 해결 가능한 경우가 많다. 2. 직접 오류를 수정하며 쌓은 기초 지식은 나중에 AI가 생성한 코드가 안전하고 정확한지 판단할 수 있는 중요한 기준이 된다. 3. 스스로 고민하고 해결하는 과정 자체가 프로그래밍 실력을 향상시키는 가장 확실한 방법이다.

Tip학습 목표

  • 대화형 인터프리터나 온라인 문서로 라이브러리 사용법을 확인한다.
Note질문

라이브러리의 중요성

  • 라이브러리(library)란 다른 프로그램에서 재사용할 수 있도록 미리 작성된 함수와 값의 모음(모듈)인다.
  • 파이썬 설치 시 기본으로 제공되는 표준 라이브러리(standard library) 외에도, PyPI(Python Package Index)를 통해 수많은 외부 라이브러리를 설치하여 사용할 수 있다.

모듈 임포트 (Import)

  • import 명령어를 사용하여 라이브러리를 프로그램으로 불러온다.
  • 불러온 후에는 모듈명.기능명 형식으로 사용한다.
import math

print('pi is', math.pi)
print('cos(pi) is', math.cos(math.pi))
  • 점(.)은 해당 모듈에 소속된 요소를 지칭할 때 사용한다.

도움말 확인: help

  • 모듈의 상세 설명과 사용법을 확인하려면 help() 함수를 사용한다.
help(math)

특정 항목만 선택하여 임포트하기

  • from ... import ... 구문을 사용하면 모듈 이름을 생략하고 특정 기능만 직접 사용할 수 있다.
from math import cos, pi

print('cos(pi) is', cos(pi))

별칭(Alias) 사용하기

  • import ... as ...를 사용하여 모듈 이름을 짧게 줄여서 부를 수 있다.
import math as m

print('cos(pi) is', m.cos(m.pi))
  • matplotlib.pyplot을 plt로, pandas를 pd로 부르는 것처럼 커뮤니티에서 통용되는 관습적인 별칭을 사용하는 것이 좋다.

제7장: 데이터를 데이터프레임으로 읽어오기

Tip학습 목표
  • Pandas 라이브러리를 임포트(import)한다.
  • Pandas로 CSV 데이터 파일을 불러온다.
  • Pandas 데이터프레임의 기본 구조와 정보를 파악한다.
Note질문
  • 표 형태의 데이터를 어떻게 효율적으로 읽고 확인할 수 있나요?

표 데이터 분석을 위한 Pandas 라이브러리

  • Pandas는 파이썬에서 표 형태의 데이터를 다루는 데 가장 널리 쓰이는 라이브러리이다.
  • 행(row)과 열(column)로 구성된 2차원 표 구조인 데이터프레임(DataFrame)을 제공한다.
  • import pandas as pd와 같이 관습적으로 pd라는 별칭을 사용하여 로드한다.
  • pd.read_csv() 함수를 사용하여 CSV 파일을 읽고 데이터프레임 객체로 변환한다.
import pandas as pd

data_oceania = pd.read_csv('data/gapminder_gdp_oceania.csv')
print(data_oceania)
  • 데이터프레임에서 열은 변수(variables), 행은 개별 관측치(observations)를 나타낸다.
  • 데이터프레임의 이름을 지을 때는 데이터의 출처나 특징이 드러나도록 명확하게 짓는 것이 관리에 도움이 된다.
Note파일 경로 주의사항

데이터 파일이 data 폴더 안에 있다면 경로에 반드시 data/를 포함해야 한다. 경로가 틀리면 파일을 찾을 수 없다는 FileNotFoundError가 발생한다.

인덱스 열 지정: index_col

  • 기본적으로 행 번호(0, 1, 2…)가 인덱스로 사용되지만 특정 열을 행의 제목(인덱스)으로 지정할 수 있다.
  • read_csv() 함수의 index_col 매개변수에 열 이름을 전달한다.
data_oceania_country = pd.read_csv('data/gapminder_gdp_oceania.csv', index_col='country')
print(data_oceania_country)

데이터프레임 정보 확인: info()

  • info() 메서드를 사용하면 데이터의 타입, 행과 열의 개수, 메모리 사용량 등을 한눈에 볼 수 있다.
data_oceania_country.info()

열 정보 확인: columns

  • DataFrame.columns는 데이터프레임의 열 이름을 담고 있는 속성(멤버 변수)인다. 함수가 아니므로 괄호 ()를 붙이지 않는다.
print(data_oceania_country.columns)

데이터프레임 전치: T

  • 행과 열을 서로 바꾸고 싶을 때 .T 속성을 사용한다. 실제 데이터를 복사하지 않고 보여주는 방식만 바꾼다.
print(data_oceania_country.T)

요약 통계 확인: describe()

  • describe() 메서드는 숫자형 데이터를 가진 열마다 개수, 평균, 표준편차, 최솟값, 최댓값 같은 요약 통계를 알려준다.
print(data_oceania_country.describe())

제8장: Pandas 데이터프레임

Tip학습 목표
  • Pandas 데이터프레임에서 특정 위치나 레이블을 사용하여 값을 선택할 수 있다.
  • 데이터프레임의 행과 열을 슬라이싱하여 부분집합(subset)을 추출할 수 있다.
  • 불리언(Boolean) 조건으로 특정 조건에 맞는 데이터를 필터링할 수 있다.
Note질문
  • 표 형태의 데이터를 어떻게 효율적으로 선택하고 분석할 수 있나요?

Pandas 데이터프레임(DataFrame)과 시리즈(Series)

  • 데이터프레임(DataFrame)은 Pandas에서 표(table) 형태의 데이터를 다루는 기본 구조다.
  • 시리즈(Series)는 데이터프레임의 각 열(column)을 나타내는 1차원 데이터 구조다.
  • Pandas는 Numpy 라이브러리를 기반으로 하여 강력한 수치 계산 능력을 갖추었고 인덱싱, 누락된 데이터 처리, 데이터 병합 등 데이터 분석에 최적화된 기능을 제공한다.

데이터 선택하기

데이터프레임에서 특정 위치의 값을 선택할 때는 두 가지 방법을 주로 사용한다.

  1. 위치 기반 선택 (iloc): 행과 열의 정수 인덱스(0, 1, 2…)를 사용하여 선택한다.
  2. 레이블 기반 선택 (loc): 행 인덱스 이름과 열 이름을 사용하여 선택한다.

위치 기반 선택: iloc

import pandas as pd
data = pd.read_csv('data/gapminder_gdp_europe.csv', index_col='country')
print(data.iloc[0, 0])  # 첫 번째 행, 첫 번째 열의 값 선택

레이블 기반 선택: loc

print(data.loc["Albania", "gdpPercap_1952"])  # 'Albania' 행, 'gdpPercap_1952' 열의 값 선택

행과 열 슬라이싱

  • :을 사용하면 해당 축의 모든 데이터를 선택한다.
print(data.loc["Albania", :])  # 'Albania' 행의 모든 열 선택
print(data.loc[:, "gdpPercap_1952"])  # 'gdpPercap_1952' 열의 모든 행 선택
  • 레이블을 사용하여 일정 범위를 슬라이싱할 수 있다. loc 슬라이싱은 마지막 레이블을 포함한다는 점에 유의해야 한다.
# 'Italy'부터 'Poland'까지의 행과 1962년부터 1972년까지의 열 선택
subset = data.loc['Italy':'Poland', 'gdpPercap_1962':'gdpPercap_1972']
print(subset)

조건부 필터링 (Boolean Masking)

  • 비교 연산자를 사용하면 데이터프레임의 각 요소에 대해 조건을 검사하고 True/False로 구성된 마스크를 생성한다.
mask = subset > 10000
print(mask)
  • 이 마스크를 원본 데이터프레임에 적용하면 조건에 맞는 값만 추출할 수 있다. 조건에 맞지 않는 위치는 NaN(Not a Number, 결측치)으로 표시된다.
print(subset[mask])

그룹화(Group By)

groupby를 사용하면 특정 기준에 따라 데이터를 나누고, 그룹별로 통계량을 계산한 뒤 다시 결합하는 분석을 할 수 있다.

# 전체 평균보다 높은지 여부를 기준으로 그룹화하여 합계 계산
mask_higher = data > data.mean()
wealth_score = mask_higher.aggregate('sum', axis=1) / len(data.columns)
print(data.groupby(wealth_score).sum())

Tip학습 목표

Note질문

리스트(List)를 사용한 데이터 저장

  • 수백 개의 데이터를 다루기 위해 매번 새로운 변수를 만드는 것은 매우 비효율적이다.
  • 연관된 데이터를 하나의 단위로 묶어서 관리하려면 리스트(list)를 사용한다.
    • 리스트는 대괄호 [...] 안에 요소들을 쉼표(,)로 구분하여 작성한다.
  • 내장 함수 len()을 사용하면 리스트에 포함된 요소의 개수를 확인할 수 있다.
pressures = [0.273, 0.275, 0.277, 0.275, 0.276]
print('pressures:', pressures)
print('length:', len(pressures))

인덱스(Index)를 이용한 요소 접근

  • 문자열과 마찬가지로 대괄호와 인덱스 번호를 사용하여 리스트의 개별 요소에 접근할 수 있다. 인덱스는 0부터 시작한다.
print('zeroth item of pressures:', pressures[0])
print('fourth item of pressures:', pressures[4])

리스트 요소 수정하기

  • 할당 연산자(=)를 사용하여 특정 인덱스의 값을 새로운 값으로 교체할 수 있다.
pressures[0] = 0.265
print('pressures is now:', pressures)

요소 추가하기: append와 extend

  • 리스트 끝에 새로운 요소를 추가하려면 append() 메서드를 사용한다.
primes = [2, 3, 5]
primes.append(7)
print('primes:', primes)
  • 메서드(Method)는 특정 객체에 종속되어 동작하는 함수이다. 객체명.메서드명() 형태로 호출한다.
  • extend() 메서드는 다른 리스트의 모든 요소를 기존 리스트 뒤에 합칠 때 사용한다.
  • 주의: append()에 리스트를 전달하면 리스트 자체가 하나의 요소로 추가되어 중첩 리스트(list of lists)가 생성된다.
primes = [2, 3, 5, 7]
primes.extend([11, 13])  # 요소들이 하나씩 추가됨
primes.append([17, 19])  # 리스트 자체가 하나의 요소로 추가됨
print(primes)

요소 삭제하기: del

  • del 키워드를 사용하여 특정 인덱스의 요소를 삭제할 수 있다. 삭제 후 리스트의 길이는 줄어든다.
primes = [2, 3, 5, 7, 9]
del primes[4]  # 인덱스 4의 요소(9) 삭제
print(primes)

빈 리스트와 다양한 타입의 혼용

  • 요소가 없는 빈 리스트([])를 생성할 수 있으며 이는 데이터를 동적으로 추가할 때 시작점으로 유용하다.
  • 하나의 리스트 안에 숫자, 문자열 등 서로 다른 타입의 데이터를 함께 담을 수 있다.
goals = [1, 'Create lists.', 2, 'Extract items.']

문자열의 인덱싱과 불변성(Immutability)

  • 문자열도 리스트처럼 인덱스로 개별 문자에 접근할 수 있다.
  • 하지만 문자열은 불변(immutable) 속성을 가지므로, 특정 인덱스의 문자를 직접 수정할 수는 없다. 수정을 원한다면 새로운 문자열을 만들어야 한다.
element = 'carbon'
print(element[0])
# element[0] = 'C'  # TypeError 발생

인덱스 범위 오류 (IndexError)

  • 리스트의 범위를 벗어난 인덱스에 접근하려고 하면 IndexError가 발생한다. 이는 프로그램 실행 중에 발생하는 런타임 오류이다.

  • 인덱스 범위를 벗어나지 않도록 주의해야 한다.

제12장: For 루프

Tip학습 목표
  • for 루프의 용도와 작동 원리를 이해한다.
  • 단순한 루프의 실행 과정을 추적하고 반복마다 변수 값이 어떻게 변하는지 파악한다.
  • 누적기(Accumulator) 패턴을 사용하여 값을 집계하는 루프를 작성한다.
Note질문
  • 프로그램이 여러 작업을 자동으로 반복하게 하려면 어떻게 해야 하나요?

for 루프를 사용한 반복 작업

  • 수백 개의 데이터를 하나씩 일일이 변수에 할당하여 계산하는 것은 매우 번거롭고 오류가 생기기 쉽다.
  • for 루프는 리스트, 문자열 등 컬렉션의 각 항목에 대해 명령을 자동으로 반복 실행하도록 파이썬에 지시한다.
  • “이 그룹에 있는 각각의 항목에 대해, 다음 작업을 수행하라”는 의미다.
for number in [2, 3, 5]:
    print(number)

위 코드는 아래와 같이 세 번의 출력 명령을 실행하는 것과 같다.

print(2)
print(3)
print(5)

for 루프의 구성 요소

for 루프는 크게 컬렉션, 루프 변수, 본문으로 구성된다.

for number in [2, 3, 5]:
    print(number)
  • 컬렉션([2, 3, 5]): 반복 대상이 되는 데이터 묶음이다.
  • 루프 변수(number): 각 반복 단계에서 컬렉션으로부터 하나씩 가져온 값을 담는 변수이다. “현재 처리 중인 항목”을 의미한다.
  • 본문(print(number)): 각 항목에 대해 실행할 명령 블록이다.

문법: 콜론과 들여쓰기

  • 루프의 첫 번째 줄은 반드시 콜론(:)으로 끝나야 한다.
  • 반복 실행될 본문 코드는 반드시 들여쓰기를 해야 한다. 파이썬은 들여쓰기로 어디까지가 루프의 본문인지 구분한다.
  • 일반적으로 스페이스 4칸을 사용하며 일관성을 유지하는 것이 중요하다.
# 들여쓰기 오류 예시 (IndentationError 발생)
# for number in [2, 3, 5]:
# print(number)

루프 변수 이름 짓기

  • 루프 변수의 이름은 일반 변수와 마찬가지로 자유롭게 지을 수 있다.
  • 가급적 루프 내부에서 다루는 데이터의 의미를 잘 나타내는 이름을 사용하는 것이 좋다.
# number 대신 다른 이름을 사용해도 작동 방식은 같습니다.
for n in [2, 3, 5]:
    print(n)

루프 본문 내의 여러 문장

  • 루프 본문에는 여러 줄의 코드가 들어갈 수 있다.
  • 하지만 루프가 너무 길어지면 코드의 흐름을 파악하기 어려우므로, 가급적 간결하게 유지하는 것이 좋다.
primes = [2, 3, 5]
for p in primes:
    squared = p ** 2
    cubed = p ** 3
    print(p, squared, cubed)

숫자 범위를 순회하는 range()

  • range(N) 함수를 사용하면 0부터 N-1까지의 숫자 시퀀스를 생성할 수 있다.
  • 이는 리스트나 문자열의 인덱스를 순회할 때 매우 유용하다.
for i in range(3):
    print(i)

누적기(Accumulator) 패턴

  • 여러 값의 합계나 결과를 하나로 모으는 일반적인 프로그래밍 패턴이다.
    1. 합계를 담을 변수(누적기)를 0이나 빈 문자열 등으로 초기화한다.
    2. 루프를 돌며 각 값을 누적기 변수에 더하거나 업데이트한다.
# 1부터 10까지의 합 구하기
total = 0
for number in range(10):
   total = total + (number + 1)
print(total)

제13장: 조건문

Tip학습 목표
  • if, else, elif를 사용하여 프로그램의 흐름을 제어하는 코드를 작성할 수 있다.
  • 루프 내부에 포함된 조건문(conditionals inside loops)의 실행 순서를 추적하고 이해한다.
Note질문
  • 데이터의 조건에 따라 서로 다른 작업(different things)을 수행하도록 하려면 어떻게 해야 하나요?

if 문을 사용한 실행 제어

  • if 문은 특정 조건(conditional)을 만족할 때만 코드가 실행되도록 제어한다.
  • 구조는 for 루프와 유사하다.
    • 첫 줄은 if로 시작하여 조건식을 적고 콜론(:)으로 끝낸다.
    • 조건이 참일 때 실행할 본문은 반드시 들여쓰기를 해야 한다.
mass = 3.54
if mass > 3.0:
    print(mass, 'is large')

mass = 2.07
if mass > 3.0:
    print (mass, 'is large')

루프 내부의 조건문

  • 조건문은 단독으로 쓰이기보다 루프 내에서 컬렉션의 각 요소를 검사하고 처리할 때 유용하게 사용된다.
masses = [3.54, 2.07, 9.22, 1.86, 1.71]
for m in masses:
    if m > 3.0:
        print(m, 'is large')

else를 사용한 예외 처리

  • else 구문은 if 문 뒤에 위치하며 조건이 거짓(not true)일 때 실행할 대안 코드(alternative)를 지정한다.
masses = [3.54, 2.07, 9.22, 1.86, 1.71]
for m in masses:
    if m > 3.0:
        print(m, 'is large')
    else:
        print(m, 'is small')

elif를 사용한 다중 조건 판단

  • 세 가지 이상의 조건 분기(several alternatives)가 필요할 때는 elif(“else if”의 약자)를 사용한다.
  • elif는 항상 if 문 뒤에 오며 여러 번 사용할 수 있다.
  • else는 모든 조건에 해당하지 않는 경우를 위해 가장 마지막에 위치해야 한다.
masses = [3.54, 2.07, 9.22, 1.86, 1.71]
for m in masses:
    if m > 9.0:
        print(m, 'is HUGE')
    elif m > 3.0:
        print(m, 'is large')
    else:
        print(m, 'is small')

조건문의 실행 순서

  • 파이썬은 조건문을 위에서 아래로 순서대로(in order) 검사한다.
  • 따라서 조건문을 배치하는 순서에 따라 결과가 달라질 수 있으므로 주의해야 한다.
grade = 85
if grade >= 90:
    print('grade is A')
elif grade >= 80:
    print('grade is B')
elif grade >= 70:
    print('grade is C')
  • 한 번 분기가 결정되어 실행된 후에는 내부에서 변수 값이 변하더라도 조건문을 다시 평가하지 않는다.
velocity = 10.0
if velocity > 20.0:
    print('moving too fast')
else:
    print('adjusting velocity')
    velocity = 50.0
  • 실시간으로 변하는 상태를 반영하려면 루프 내에 조건문을 포함시켜야 한다.
velocity = 10.0
for i in range(5):
    print(i, ':', velocity)
    if velocity > 20.0:
        print('moving too fast')
        velocity = velocity - 5.0
    else:
        print('moving too slow')
        velocity = velocity + 10.0
print('final velocity:', velocity)

실행 과정 추적하기 (Tracing)

프로그램의 동작을 이해하려면 시간에 따른 변수의 변화를 표(table)로 그려보는 것이 좋다.

velocity 10.0 20.0 30.0 25.0 20.0
Noteand, or 및 괄호를 활용한 복합 조건식

여러 조건을 동시에 만족해야 하거나 하나만 만족해도 되는 경우 and(그리고)와 or(또는) 논리 연산자를 사용한다.

velocity = [10.00, 20.00, 30.00, 25.00, 20.00]

for i in range(5):
    if mass[i] > 5 and velocity[i] > 20:
        print("Fast heavy object.")
    elif mass[i] > 2 and mass[i] <= 5 and velocity[i] <= 20:
        print("Normal traffic")
    elif mass[i] <= 2 and velocity[i] <= 20:
        print("Slow light object.")
    else:
        print("Check the data.")

조건이 복잡해질 때는 소괄호 ()를 사용하여 우선순위를 명확히 하는 것이 좋다. and와 or가 혼용될 때는 괄호를 사용하여 의도를 분명히 밝히라.

if (mass[i] <= 2 or mass[i] >= 5) and velocity[i] > 20:
    # (질량이 2 이하이거나 5 이상인 경우)이면서 속도가 20 초과인 경우

최솟값과 최댓값 찾기

리스트에서 최솟값과 최댓값을 찾는 다음 코드를 완성하라. None을 활용하여 초기화하는 방법에 유의해야 한다.

#| eval: false
values = [-2, 1, 65, 78, -54, -24, 100]

for v in values:
    if smallest is None or v < smallest:
        smallest = v
    if largest is None or v > largest:
        largest = v
print(smallest, largest)

참고: 파이썬에서는 == None보다 is None을 사용하는 것을 권장한다. 또한, 실제로는 내장 함수 min()과 max()를 사용하는 것이 가장 효율적이다.

  • else는 조건이 거짓일 때 실행할 코드를 지정한다.
  • elif는 여러 개의 조건을 순차적으로 검사할 때 사용한다.
  • 조건문은 위에서 아래로 순서대로 한 번만 평가된다.

제14장: 데이터 세트 순회하기

Tip학습 목표
  • 여러 파일 이름을 한꺼번에 지정할 수 있는 글로빙(globbing) 패턴을 이해하고 사용한다.
  • glob 라이브러리를 사용하여 조건에 맞는 파일 목록을 생성한다.
  • 파일 목록을 바탕으로 for 루프를 사용하여 여러 파일에 대해 동일한 작업을 일괄 처리하는 코드를 작성한다.
Note질문
  • 여러 개의 데이터 파일을 한 번에 처리하려면 어떻게 해야 하나요?

파일 이름 목록을 사용하여 for 루프로 파일을 일괄 처리한다.

  • 파일 이름은 문자열 데이터이다.
  • 파이썬 리스트를 사용하여 여러 파일 이름을 저장하고 관리할 수 있다.
import pandas as pd
for filename in ['data/gapminder_gdp_africa.csv', 'data/gapminder_gdp_asia.csv']:
    data = pd.read_csv(filename, index_col='country')
    print(filename, data.min())

glob.glob을 사용하여 패턴에 일치하는 파일들을 찾는다.

  • 유닉스(Unix) 시스템에서 “글로빙(globbing)”은 특정 패턴과 일치하는 파일 집합을 찾는 것을 의미한다.
  • 가장 흔히 사용되는 패턴 기호는 다음과 같다:
    • * : 0개 이상의 임의의 문자와 일치하는 와일드카드.
    • ? : 정확히 하나의 문자와 일치하는 기호.
  • 파이썬의 표준 라이브러리인 glob 모듈은 이런 파일 패턴 매칭 기능을 제공한다.
  • glob.glob('*.txt')와 같이 실행하면 현재 디렉터리에서 확장자가 .txt인 모든 파일의 목록을 리스트 형태로 반환한다. 만약 일치하는 파일이 없다면 빈 리스트를 반환한다.
import glob
print('data 디렉터리 안의 모든 csv 파일:', glob.glob('data/*.csv'))
print('모든 PDB 파일:', glob.glob('*.pdb'))

glob과 for 루프를 결합하여 여러 파일을 일괄(batch) 처리한다.

  • 파일들이 일관된 규칙에 따라 이름 지어져 있다면, 간단한 패턴만으로 원하는 파일을 쉽게 찾아내어 처리할 수 있다.
for filename in glob.glob('data/gapminder_*.csv'):
    data = pd.read_csv(filename)
    print(filename, data['gdpPercap_1952'].min())
  • 위 코드의 결과에는 지역별 데이터뿐만 아니라 gapminder_all.csv와 같은 전체 데이터 세트도 포함될 수 있다.
  • 특정 파일을 제외하거나 더 구체적인 대상을 지정하려면 패턴을 더 정교하게 작성해야 한다.
  • 전체 통합 데이터의 최솟값이 특정 지역 데이터의 최솟값과 일치하는지 확인하는 것은 코드가 올바르게 작동하는지 검증하는 좋은 방법이 될 수 있다.

함수를 사용한 코드 모듈화

  • 인간의 기억력에는 한계가 있어 한 번에 너무 많은 정보를 처리하기 어렵다.
  • 따라서 복잡한 아이디어를 이해하려면 세부 사항을 결합하여 더 큰 단위로 구조화해야 한다.
    • 이는 거대한 기계 장치의 부품들이나 수학 증명의 보조정리와 같은 역할을 한다.
  • 프로그래밍에서 함수(functions)는 바로 이런 목적을 위해 존재한다.
    • 캡슐화(Encapsulation)로 복잡한 과정을 하나의 단위로 묶어 관리할 수 있다.
  • 함수는 한 번 작성해 두면 필요할 때마다 여러 번 재사용할 수 있다는 장점이 있다.

함수 정의하기

  • 파이썬에서 함수를 정의할 때는 def 키워드를 사용한다.
  • def 뒤에 함수의 이름을 적다. 이름은 변수 명명 규칙과 동일하게 작성한다.
  • 이름 뒤의 괄호 안에 매개변수(parameters)라고 불리는 입력값 변수들을 나열한다. 입력값이 없다면 빈 괄호 ()를 사용한다.
  • 줄 끝에 콜론 :을 붙이고 다음 줄부터 들여쓰기를 하여 함수의 본문을 작성한다.
def print_greeting():
    print('Hello!')
    print('The weather is nice today.')
    print('Right?')

함수 호출하기

  • 함수를 정의하는 것만으로는 코드가 실행되지 않는다. 변수에 값을 할당하는 것과 유사하게 함수를 저장해 두는 단계이다.
  • 함수 내부의 코드를 실제로 실행하려면 함수의 이름을 써서 명시적으로 호출(call)해야 한다.
print_greeting()

인수(Arguments)와 매개변수(Parameters)

  • 함수가 다양한 데이터를 처리할 수 있도록 매개변수를 지정한다.
  • 매개변수는 함수 내부에서 사용할 임시 변수 역할을 한다.
  • 함수를 호출할 때 전달하는 실제 데이터를 인수(Arguments)라고 하며 이 인수는 매개변수에 순서대로 할당된다.
def print_date(year, month, day):
    joined = str(year) + '/' + str(month) + '/' + str(day)
    print(joined)

  • 호출 시 매개변수의 이름을 직접 지정하여 인수를 전달할 수도 있다. 이 경우 순서가 바뀌어도 상관없으며 코드가 더 명확해진다.
print_date(month=3, day=19, year=1871)

return 문을 통한 결과 반환

  • 함수 실행 결과를 호출한 곳으로 돌려주려면 return 구문을 사용한다.
  • return 문은 함수 내 어디든 위치할 수 있지만 주로 다음과 같은 경우에 사용한다.
    • 함수의 시작 부분: 잘못된 입력 등을 확인하여 즉시 종료할 때.
    • 함수의 마지막 부분: 모든 로직을 마친 후 최종 결과를 반환할 때.
def average(values):
    if len(values) == 0:
        return None
    return sum(values) / len(values)

def logistic_map(x, r):
    return r * x * (1 - x)

def iterate(initial_population, t_final, r):
    population = [initial_population]
    for t in range(t_final):
        population.append(logistic_map(population[t], r))
    return population

변수의 범위 (Variable Scope)

  • 함수 내부에서 정의된 매개변수나 변수는 함수 외부에서는 보이지 않는다. 이를 변수의 범위(scope)라고 한다.
  • 함수 내부에서만 유효한 변수를 지역 변수(local variables)라고 부른다.
pressure = 103.9

def adjust(t):
    temperature = t * 1.43 / pressure
    return temperature
  • 위 코드에서 pressure는 함수 외부에서 정의된 전역 변수(global variable)인다. 함수 내부에서도 이 값을 읽을 수 있다.
  • 반면 adjust 함수 내부의 t와 temperature는 지역 변수이다. 함수 실행이 끝나면 이 변수들은 더 이상 존재하지 않는다.
# print(temperature)  # NameError 발생: temperature는 정의되지 않음

오류 메시지(Traceback) 읽기

오류가 발생하면 파이썬은 트레이스백(traceback)이라는 메시지를 출력한다. 이 메시지에는 오류를 해결하는 데 필요한 핵심 정보가 담겨 있다.

  1. 에러의 종류: 마지막 줄의 첫 단어 (예: NameError, IndexError, KeyError 등).
  2. 에러 내용: 종류 뒤에 이어지는 구체적인 설명.
  3. 발생 위치: 오류가 발생한 파일 이름과 줄 번호.
  4. 호출 경로: 함수가 중첩되어 호출된 경우, 어떤 경로를 거쳐 오류 지점에 도달했는지 보여준다.

코딩 스타일 (Coding style)

일관된 코딩 스타일은 다른 사람(또는 미래의 자신)이 코드를 더 쉽게 읽고 이해할 수 있도록 도와준다. 코드는 작성되는 시간보다 읽히는 시간이 훨씬 더 길기 때문이다. 파이썬의 선(Zen of Python)에서도 “가독성은 중요하다(Readability counts)”라고 명시하고 있다. 파이썬 공동체에서는 공식 코딩 스타일 가이드인 PEP 8을 제정하여 권장하고 있다.

특히 강조할 만한 몇 가지 사항은 다음과 같다:

  • 코드에 주석(comments)을 달아, 어떤 가정을 하고 있는지, 알고리즘의 의도가 무엇인지, 그리고 예상되는 입력과 출력이 무엇인지 설명하라.
  • 변수 이름을 지을 때는 의미가 명확하고 직관적인 이름(semantically meaningful variable names)을 선택하라.
  • 들여쓰기를 할 때는 탭(tabs) 대신 공백(spaces)을 사용하라. 탭 문자는 에디터나 운영체제마다 다르게 해석될 수 있어 코드의 형식이 깨질 위험이 있다.

표준 파이썬 스타일 가이드를 준수하라.

  • PEP 8: 파이썬의 공식 코딩 스타일 가이드라인으로, 변수 명명법, 들여쓰기 칸수, import 문 배치 등 상세한 규칙을 다룬다. PEP 8을 준수하면 다른 개발자들이 여러분의 코드를 이해하기 쉬워지며 협업 시 일관성을 유지할 수 있다.
  • 코드가 PEP 8을 잘 지키고 있는지 검사하려면 pycodestyle 도구를 사용하거나, 코드를 자동으로 포맷팅해 주는 black과 같은 도구를 활용할 수 있다. 주피터 노트북 환경을 위한 nb_black도 있다.
  • 구글과 같은 일부 조직에서는 PEP 8을 기반으로 수정한 자체 가이드를 사용하기도 한다. 예를 들어 구글 파이썬 스타일 가이드가 있다. 구글은 yapf라는 도구를 만들어 다양한 스타일로 자동 포맷팅을 지원한다.
  • 결국 코딩 스타일에서 가장 중요한 것은 일관성(consistency)인다. 프로젝트에서 특정 스타일을 따르기로 결정했다면, 모든 협업자가 해당 규칙을 준수하도록 해야 한다. 일관성 없는 다양한 스타일을 섞어 쓰는 것보다 하나의 규칙을 일관되게 유지하는 것이 코드의 파악과 유지보수에 훨씬 유리하다.

assert를 사용하여 예상치 못한 오류를 감지하라.

단언문(Assertions)은 코드 실행 중에 특정 조건이 의도한 대로 유지되고 있는지 확인하는 간단하고 강력한 방법이다.

def calc_bulk_density(mass, volume):
    '''벌크 밀도 반환 = 질량 / 부피'''
    assert volume > 0  # 부피는 반드시 양수여야 함
    return mass / volume

만약 assert 뒤의 조건이 False가 되면, 파이썬은 AssertionError를 발생시켜 프로그램을 중단한다. 에러 메시지에는 어떤 코드에서 문제가 발생했는지 표시되어 원인을 파악하기 쉽다. 참고로, 파이썬을 실행할 때 -O (optimize) 옵션을 사용하면 모든 assert 문을 무시하고 실행할 수 있다. 주의할 점은 assert를 프로그램의 상태를 변경하는 용도로 사용해서는 안 된다는 것이다. 예를 들어 단언문 안에서 변수에 값을 대입하는 등의 작업은 피해야 한다.

독스트링(docstrings)을 사용하여 함수 설명을 작성하라.

# 이 주석은 시퀀스 집합 내의 최대 거리를 탐색하는 역할을 설명합니다.

def overall_max(sequences):
    '''모든 시퀀스 쌍 중에서 최대 편집 거리를 계산하여 반환합니다.'''

    highest = 0
    for left in sequences:
        for right in sequences:
            '''자기 자신과 비교하는 경우는 제외합니다.'''
            if left != right:
                this = edit_distance(left, right)
                highest = max(highest, this)

    return highest

#| eval: false
def transform_string(input_string, iterations):
    """
    입력된 문자열을 지정된 횟수만큼 변형하여 출력합니다.
    변형 규칙: 인접한 두 문자가 같으면 '-', 다르면 '*'를 사용합니다.
    """
    print(input_string)
    length = len(input_string)
    current = input_string

    for _ in range(iterations):
        new_chars = []
        for i in range(length):
            left = i - 1
            right = (i + 1) % length
            if current[left] == current[right]:
                new_chars.append('-')
            else:
                new_chars.append('*')

        current = ''.join(new_chars)
        print(current)

transform_string('et cetera', 10)
