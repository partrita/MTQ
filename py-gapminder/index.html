제1장: 실행과 종료

Tip학습 목표
  • JupyterLab 서버를 실행하고 종료한다.
  • 새로운 파이썬 스크립트와 Jupyter 노트북을 생성한다.
  • 파이썬 스크립트와 Jupyter 노트북의 차이점을 이해한다.
  • 노트북에서 마크다운(Markdown) 셀을 생성하고 편집한다.
  • 노트북에서 파이썬 코드 셀을 생성하고 실행한다.
Note핵심 질문
  • 파이썬 프로그램은 어떻게 실행하는가?

이 실습에서는 파이썬을 실행하기 위해 JupyterLab 환경에서 동작하는 Jupyter Notebook을 사용한다. Jupyter 노트북은 코드를 대화형으로 실행하고, 분석 결과와 시각화 차트를 즉시 확인하며 공유할 수 있어 데이터 과학 분야에서 널리 쓰인다.

코드를 작성하고 실행하는 방법은 다양하다. 소프트웨어 개발자들은 주로 PyCharm이나 Visual Studio Code 같은 통합 개발 환경(IDE), 또는 Vim이나 Emacs 같은 텍스트 편집기를 사용한다. 이 경우 코드를 파일로 저장한 뒤 터미널(명령줄)이나 IDE 내에서 실행한다. 반면 Jupyter 노트북은 웹 브라우저 안에서 코드 작성과 실행, 결과 확인을 한 번에 처리할 수 있다.

JupyterLab의 주요 장점은 다음과 같다:

  • 코드 블록을 쉽게 작성, 편집, 복사, 붙여넣기 할 수 있다.
  • 탭 자동 완성(Tab completion)으로 변수, 함수, 객체 이름을 손쉽게 검색하고 조회할 수 있다.
  • 마크다운을 지원하여 제목, 서식 있는 텍스트, 링크, 글머리 기호 등을 코드와 함께 깔끔하게 문서화할 수 있다.
  • 그래프 생성 코드 바로 아래에 결과 이미지를 표시하므로 데이터 분석 흐름을 직관적으로 파악할 수 있다.

각 노트북은 코드 셀, 마크다운 텍스트 셀, 출력 이미지 등으로 구성된다.

JupyterLab 시작하기

JupyterLab은 Project Jupyter에서 개발한 웹 기반 차세대 사용자 인터페이스로, 노트북, 텍스트 편집기, 터미널 등 다양한 도구를 단일 작업 공간에서 유연하게 다룰 수 있도록 지원한다. JupyterLab은 최신 웹 브라우저(Chrome, Safari, Firefox 등)에 최적화되어 있다.

JupyterLab은 Anaconda 파이썬 배포판에 기본 포함되어 있다. 아직 설치하지 않았다면 설정 안내를 참고하여 설치한다.

본 실습에서는 로컬 컴퓨터에서 JupyterLab 서버를 직접 구동하므로, 최초 설치 이후에는 인터넷 연결 없이도 동작한다.

  • 로컬 기기에서 JupyterLab 서버를 실행한다.
  • 웹 브라우저가 localhost URL로 서버에 연결된다.
  • 브라우저에 코드를 입력하면 로컬 서버가 연산을 수행하고 결과를 브라우저 화면에 렌더링한다.
NoteJupyterLab과 기존 Jupyter Notebook의 차이

JupyterLab은 기존 Jupyter Notebook의 차세대 진화 버전이다. 기존 노트북의 기능을 모두 포괄하면서, 여러 탭 분할 배치, 파일 탐색기, 터미널 통합 등 한층 확장된 작업 환경을 제공한다. 자세한 인터페이스 비교는 JupyterLab 인터페이스 문서를 참고하자.

JupyterLab 실행하기

JupyterLab 서버는 터미널(커맨드 라인) 또는 Anaconda Navigator를 통해 실행할 수 있다.

macOS - 터미널

  1. 응용 프로그램(Applications) > 유틸리티(Utilities) > 터미널(Terminal)을 실행하거나, Command + Space로 Spotlight를 열고 Terminal을 검색하여 실행한다.

Windows - Anaconda Prompt

  1. Windows 로고 키를 누르고 Anaconda Prompt를 검색하여 실행한다.
  2. 창에 다음 명령어를 입력한다:
jupyter lab

Anaconda Navigator

Anaconda Navigator 그래픽 인터페이스에서도 시작할 수 있다. Navigator를 실행한 후 JupyterLab 타일 아래의 Launch 버튼을 클릭한다.

JupyterLab 인터페이스 구조

JupyterLab 인터페이스는 상단 메뉴 바(Menu Bar), 좌측 사이드바(Left Sidebar), 메인 작업 영역(Main Work Area)의 세 영역으로 구성된다.

1. 상단 메뉴 바 (Menu Bar)

JupyterLab의 모든 기본 기능을 제어한다:

  • File (파일): 새 파일/노트북 생성, 열기, 저장, 내보내기, 서버 종료(Shut Down)
  • Edit (편집): 셀 및 텍스트 실행 취소(Undo), 잘라내기, 복사, 붙여넣기 등
  • View (보기): 사이드바 표시 여부, 줄 번호 표시, 테마 설정 등
  • Run (실행): 코드 셀 실행, 전체 셀 일괄 실행 등
  • Kernel (커널): 파이썬 연산 엔진 재시작, 중단, 커널 변경 등
  • Tabs (탭): 현재 열려 있는 문서 및 작업 목록
  • Settings (설정): 환경설정 및 단축키 조정(Advanced Settings Editor)
  • Help (도움말): 공식 문서 및 도움말 링크 모음
Note커널 (Kernel)이란?

커널은 사용자가 입력한 코드를 실제로 해석하고 실행하는 백그라운드 프로세스이다. Jupyter 노트북을 열면 기본적으로 파이썬 3 코드를 실행하는 ipython 커널이 함께 시작된다. Jupyter는 다양한 언어 커널을 지원하므로 R, Julia, JavaScript 등 다른 언어도 동일한 환경에서 실행할 수 있다.

2. 좌측 사이드바 (Left Sidebar)

파일 브라우저(디렉터리 탐색), 실행 중인 커널/터미널 목록, 명령어 팔레트(Command Palette), 열린 탭 목록 등을 제공한다. 활성화된 사이드바 아이콘을 다시 클릭하거나 View -> Show Left Sidebar로 접고 펼칠 수 있다.

3. 메인 작업 영역 (Main Work Area)

노트북, 텍스트 파일, 터미널 등을 탭으로 열어 작업하는 공간이다. 패널 가장자리로 탭을 드래그하면 화면을 상하/좌우로 분할하여 다중 창 배치가 가능하다.

파이썬 스크립트(.py) 만들기

  • Launcher 탭의 Other 항목에서 Text File을 클릭한다 (또는 File -> New -> Text File).
  • 파일을 저장할 때 File -> Save File As...를 선택하고 확장자를 .py로 지정한다 (예: script.py).
  • .py 확장자는 이 파일이 파이썬 스크립트임을 나타낸다.

Jupyter 노트북(.ipynb) 만들기

  • Launcher 탭의 Notebook 항목에서 Python 3 아이콘을 클릭한다 (또는 File -> New -> Notebook).
  • 노트북 파일은 .ipynb(Interactive Python Notebook) 확장자로 저장된다.
  • 노트북은 내부적으로 JSON 형식으로 저장되며, 코드, 텍스트(마크다운), 실행 결과, 차트 이미지가 하나의 파일에 통합 보관된다.

작업 창 패널 분할 배치 연습

  2. 노트북, 터미널, 텍스트 파일을 열어 가장 작업하기 편리한 배치 구조를 구성해 보자.
Caution해답

탭 헤더를 드래그하여 패널의 왼쪽, 오른쪽, 위쪽, 아래쪽 가장자리로 가져가면 파란색 영역이 표시되며 해당 방향으로 화면이 분할된다.

노트북의 두 가지 모드: 명령(Command) 모드와 편집(Edit) 모드

노트북의 셀은 명령 모드와 편집 모드 두 가지 상태로 조작한다:

  • 편집 모드 (Edit Mode, 테두리 파란색): 셀 내부의 코드나 텍스트를 직접 입력·수정하는 상태이다. Enter를 누르면 진입한다.
  • 명령 모드 (Command Mode, 테두리 회색/파란 막대): 셀 전체의 위치 이동, 생성, 삭제 등 구조를 조작하는 상태이다. Esc를 누르면 진입한다.

명령 모드 주요 단축키:

  • A: 현재 셀 위에(Above) 새 셀 추가
  • B: 현재 셀 아래에(Below) 새 셀 추가
  • D + D (또는 X): 선택한 셀 삭제
  • Z: 셀 삭제/조작 실행 취소(Undo)
  • M: 현재 셀을 마크다운(Markdown) 셀로 전환
  • Y: 현재 셀을 파이썬 코드(Code) 셀로 전환
Important연습 문제

명령 모드와 편집 모드 단축키 실습

  1. Esc와 Enter를 눌러 두 모드를 전환해 보자.
  2. 명령 모드에서 B를 눌러 새 셀을 만들고, Enter를 눌러 코드를 입력해 보자.
  3. Esc를 누른 뒤 D + D로 해당 셀을 삭제하고, Z를 눌러 복구해 보자.
Caution해답
  • 파란 테두리(또는 커서 깜빡임): 편집 모드
  • 회색 테두리: 명령 모드
  • Esc \(\rightarrow\) B \(\rightarrow\) Enter \(\rightarrow\) Esc \(\rightarrow\) D, D \(\rightarrow\) Z 순으로 조작한다.

셀 실행하기

  • 셀 실행: Shift + Enter를 누르면 현재 셀이 실행되고 바로 다음 셀로 이동한다.
  • 현재 셀만 실행: Ctrl + Enter를 누르면 셀을 실행한 뒤 포커스를 그대로 유지한다.

마크다운(Markdown)으로 서식 있는 문서 작성하기

  • 다시 코드 셀로 바꾸려면 명령 모드에서 Y를 누른다.

Note핵심 질문

변수를 사용하여 값을 저장한다

  • 변수(Variable)는 메모리에 저장된 값에 붙이는 이름이다.
  • 변수 명명 규칙:
  • 영문자, 숫자, 밑줄(_)만 포함할 수 있다.
  • 숫자로 시작할 수 없다.
  • 대소문자를 엄격히 구분한다 (age, Age, AGE는 서로 다른 변수이다).
  • 변수 이름은 데이터의 의미를 명확히 알 수 있도록 직관적으로 짓는다.
  • 파이썬에서 = 기호는 오른쪽 값을 왼쪽 변수에 대입(할당)함을 뜻한다.
age = 42
first_name = 'Ahmed'

print() 함수로 값 출력하기

  • print() 함수는 전달받은 값을 화면에 출력한다.
  • 함수를 실행하는 것을 호출(call)이라 하고, 괄호 안에 넘겨주는 값을 인수(argument)라고 한다.
print(first_name, 'is', age, 'years old')
  • print()는 여러 인수를 쉼표로 구분해 전달받으면 공백을 사이에 두고 출력하며, 끝에 줄바꿈을 자동으로 추가한다.

변수는 사용 전에 먼저 정의되어야 한다

  • 정의되지 않은 변수를 참조하거나 오타를 내면 NameError가 발생한다.
# print(last_name)  # NameError: name 'last_name' is not defined
NoteJupyter Notebook의 셀 실행 순서

Jupyter Notebook에서는 셀의 물리적 위치보다 실행된 순서가 중요하다. 위쪽 셀이라도 실행하지 않았다면 그 안의 변수는 정의되지 않은 상태이다. 실행 순서가 꼬여 변수 상태가 불분명할 때는 메뉴에서 Kernel -> Restart & Run All을 실행하여 처음부터 순서대로 다시 계산하자.

변수를 활용한 연산

  • 변수는 수식에서 실제 값과 똑같이 다뤄진다.
age = age + 3
print('Age in three years:', age)

인덱싱(Indexing): 개별 문자 추출

  • 문자열 내 각 문자는 고유한 위치 번호인 인덱스(index)를 가진다.
  • 파이썬의 인덱스는 0부터 시작한다.
  • 대괄호 [] 안에 인덱스를 넣어 해당 위치의 문자를 추출한다.
atom_name = 'helium'
print(atom_name[0])  # 'h'

슬라이싱(Slicing): 부분 문자열 추출

  • 문자열의 일부 구간을 잘라낸 것을 부분 문자열(substring)이라 한다.
  • [start:stop] 구문으로 슬라이싱하며, start부터 stop 직전(stop-1)까지의 문자를 반환한다.
  • 슬라이싱은 원본 문자열을 변경하지 않고 새로운 복사본 문자열을 생성한다.
atom_name = 'sodium'
print(atom_name[0:3])  # 인덱스 0, 1, 2에 해당하는 'sod' 추출

문자열 길이 확인: len()

  • len() 내장 함수는 문자열의 전체 문자 수를 반환한다.
print(len('helium'))  # 6

명확한 변수명 작성하기

  • 문법적으로 유효하더라도 의미 없는 변수명보다는 의도가 분명한 이름을 사용해야 협업과 유지보수가 수월하다.
# 피해야 할 예
flabadab = 42

# 권장하는 예
age = 42

제3장: 데이터 타입과 타입 변환

Tip학습 목표

  • 숫자와 문자열의 특성 차이를 파악한다.
  • 내장 형변환 함수를 사용하여 데이터 타입을 변환한다.

모든 값에는 데이터 타입(Type)이 있다

  • 정수 (int): 3, -512와 같이 소수점이 없는 숫자
  • 부동소수점 숫자 (float): 3.14, -2.5와 같이 소수점을 포함하는 실수
  • 문자열 (str): 작은따옴표(')나 큰따옴표(")로 감싼 텍스트 데이터

type() 함수로 타입 확인하기

  • 변수나 값의 데이터 타입을 확인할 때는 type() 함수를 사용한다.
print(type(52))          # <class 'int'>
fitness = 'average'
print(type(fitness))     # <class 'str'>

타입에 따른 연산 제한

  • 각 연산자는 데이터 타입에 따라 다르게 동작하며, 호환되지 않는 타입끼리 연산하면 오류가 발생한다.
print(5 - 3)
# print('hello' - 'h')  # TypeError: unsupported operand type(s) for -: 'str' and 'str'

문자열의 연결과 반복

  • + 연산자: 두 문자열을 하나로 이어 붙인다(Concatenation).
  • * 연산자: 문자열을 정수 횟수만큼 반복한다.
full_name = 'Ahmed' + ' ' + 'Walsh'
print(full_name)
print('=' * 10)

len()과 숫자 데이터

  • len() 함수는 문자열이나 리스트 같은 컬렉션의 길이를 반환하며, 단일 숫자(int, float)에는 사용할 수 없다.
print(len(full_name))
# print(len(52))  # TypeError: object of type 'int' has no len()

명시적 타입 변환 (Type Casting)

  • 숫자와 문자열을 직접 더하면 TypeError가 발생하므로, int(), float(), str() 함수로 타입을 명시적으로 일치시켜야 한다.
print(1 + int('2'))   # 3 (정수 연산)
print(str(1) + '2')   # '12' (문자열 연결)

정수와 부동소수점 숫자의 혼합 연산

  • 정수와 부동소수점 숫자를 함께 연산하면, 파이썬은 결과를 자동으로 float 타입으로 승격 변환한다.
print('half is', 1 / 2.0)
print('three squared is', 3.0 ** 2)

라이브러리의 개념

  • 라이브러리(Library)는 재사용 가능한 함수, 클래스, 상수의 묶음(모듈)이다.
  • 파이썬에는 기본 제공되는 표준 라이브러리(Standard Library)와, PyPI를 통해 배포되는 수많은 서드파티 라이브러리가 존재한다.

모듈 임포트 (import)

  • import 모듈명으로 라이브러리를 불러오며, 모듈명.기능명 형식으로 호출한다.
import math

print('pi is', math.pi)
print('cos(pi) is', math.cos(math.pi))

특정 기능만 직접 가져오기 (from ... import ...)

  • from 모듈명 import 함수명 구문을 사용하면 모듈명 접두사 없이 함수를 직접 호출할 수 있다.
from math import cos, pi

print('cos(pi) is', cos(pi))

별칭 지정하기 (import ... as ...)

  • 긴 라이브러리 이름을 축약하여 사용하려면 as 키워드를 사용한다.
import math as m

print('cos(pi) is', m.cos(m.pi))
  • 관례적으로 pandas는 pd, numpy는 np, matplotlib.pyplot은 plt로 축약하여 사용한다.

데이터프레임(DataFrame)과 시리즈(Series)

  • DataFrame: 행과 열로 이루어진 2차원 표 구조
  • Series: 데이터프레임의 단일 열을 이루는 1차원 데이터 배열

데이터 선택: iloc과 loc

  1. 위치 기반 인덱서 (iloc): 0부터 시작하는 정수 인덱스로 행과 열을 지정한다.
  2. 레이블 기반 인덱서 (loc): 행 인덱스 이름과 열 이름을 직접 지정한다.
import pandas as pd
data = pd.read_csv('data/gapminder_gdp_europe.csv', index_col='country')

# 위치 기반 선택 (0번째 행, 0번째 열)
print(data.iloc[0, 0])

# 레이블 기반 선택 ('Albania' 행, 'gdpPercap_1952' 열)
print(data.loc["Albania", "gdpPercap_1952"])

행과 열 슬라이싱

  • 전체 행 또는 열을 선택할 때는 콜론(:)을 사용한다.
  • loc 슬라이싱은 끝 레이블을 포함한다는 점에 유의한다 (iloc은 끝 인덱스를 제외).
# 'Albania' 행의 모든 열 선택
print(data.loc["Albania", :])

# 'Italy'부터 'Poland'까지, 1962년부터 1972년까지 슬라이싱
subset = data.loc['Italy':'Poland', 'gdpPercap_1962':'gdpPercap_1972']
print(subset)

조건부 필터링 (Boolean Masking)

  • 데이터프레임에 비교 연산자를 적용하면 True/False로 구성된 불리언 마스크가 생성된다.
  • 이 마스크를 데이터프레임에 적용하면 조건에 맞는 값만 추출할 수 있다.
mask = subset > 10000
print(subset[mask])

그룹화 집계 (groupby)

  • groupby() 메서드를 사용하면 특정 기준에 따라 데이터를 그룹으로 분할하고 집계 통계량을 계산할 수 있다.
# 유럽 전체 평균보다 높은지 여부를 기준으로 그룹화
mask_higher = data > data.mean()
wealth_score = mask_higher.aggregate('sum', axis=1) / len(data.columns)
print(data.groupby(wealth_score).sum())

리스트(List) 생성과 기본 조작

  • 리스트는 대괄호 [...] 안에 여러 요소를 쉼표(,)로 구분하여 정의한다.
  • len() 함수로 요소의 개수를 구한다.
pressures = [0.273, 0.275, 0.277, 0.275, 0.276]
print('pressures:', pressures)
print('length:', len(pressures))

인덱싱과 요소 수정 (가변성, Mutability)

  • 0부터 시작하는 인덱스를 사용하여 특정 위치의 요소에 접근하고 새 값을 대입하여 수정할 수 있다.
print('첫 번째 값:', pressures[0])
pressures[0] = 0.265
print('수정된 리스트:', pressures)

리스트 확장: append() vs extend()

  • append(x): 리스트 맨 끝에 요소 x 하나를 추가한다.
  • extend(iterable): 다른 컬렉션의 모든 요소를 기존 리스트 끝에 이어 붙인다.
primes = [2, 3, 5]
primes.append(7)
primes.extend([11, 13])
print(primes)  # [2, 3, 5, 7, 11, 13]

요소 삭제: del

primes = [2, 3, 5, 7, 9]
del primes[4]  # 인덱스 4의 9 삭제
print(primes)  # [2, 3, 5, 7]

문자열의 불변성(Immutability) vs 리스트의 가변성(Mutability)

  • 문자열은 인덱싱이 가능하지만 특정 위치의 문자를 직접 바꿀 수 없는 불변(immutable) 객체이다.
  • 반면 리스트는 자유롭게 요소를 수정, 추가, 삭제할 수 있는 가변(mutable) 객체이다.
element = 'carbon'
# element[0] = 'C'  # TypeError: 'str' object does not support item assignment

  • sorted(list): 원본 리스트는 유지하고 정렬된 새로운 리스트를 생성하여 반환한다.
Important연습 문제

참조(Reference) vs 복사(Copy)

b = a와 b = a[:]의 차이점은 무엇인가?

Caution해답
  • b = a: 동일한 메모리 주소를 참조하므로 b를 수정하면 a도 함께 변경된다.
  • b = a[:]: 리스트의 얕은 복사본(shallow copy)을 생성하므로 b를 수정해도 a에 영향을 주지 않는다.
Note핵심 요약
  • 리스트는 가변적인 순서형 컬렉션이다.
  • 인덱싱으로 개별 요소를 수정하고, append(), extend(), del로 크기를 조절한다.
  • 문자열은 불변 객체이고 리스트는 가변 객체이다.

Tip학습 목표

if, elif, else 기본 구조

mass = 3.54

if mass > 9.0:
    print(mass, 'is HUGE')
elif mass > 3.0:
    print(mass, 'is large')
else:
    print(mass, 'is small')
  • 조건식은 위에서 아래로 순서대로 평가되며, 최초로 참(True)이 되는 하나의 블록만 실행되고 조건문을 빠져나온다.
  • 어떤 조건도 만족하지 않을 경우 else 블록이 실행된다.

루프 내부의 조건문

masses = [3.54, 2.07, 9.22, 1.86, 1.71]

for m in masses:
    if m > 3.0:
        print(m, 'is large')
    else:
        print(m, 'is small')

변수 추적표 (Tracing Table)

velocity = 10.0
for i in range(5):
    if velocity > 20.0:
        velocity = velocity - 5.0
    else:
        velocity = velocity + 10.0
반복 단계 (\(i\)) 시작 속도 조건 평가 종료 속도
0 10. \(\le 20.0\) (else) 20.
1 20. \(\le 20.0\) (else) 30.
2 30. \(> 20.0\) (if) 25.
3 25. \(> 20.0\) (if) 20.
4 20. \(\le 20.0\) (else) 30.

복합 논리 연산자 (and, or, not)

  • and: 모든 조건이 참이어야 참
  • or: 조건 중 하나 이상이 참이면 참
  • 복잡한 조건문에서는 소괄호 ()를 사용하여 우선순위를 명확히 지정한다.

로지스틱 맵 시뮬레이션 함수

  2. 초기 개체군에서 시작하여 \(t\) 세대 동안의 변화 리스트를 생성하는 iterate(initial_x, t_final, r) 함수로 캡슐화해 보자.

def logistic_map(x, r):
    return r * x * (1 - x)

def iterate(initial_population, t_final, r):
    population = [initial_population]
    for t in range(t_final):
        population.append(logistic_map(population[-1], r))
    return population

print(iterate(0.5, 10, 1.0))

지역 변수(Local Variable)와 전역 변수(Global Variable)

  • 지역 변수 (Local Variable): 함수 내부에서 선언되거나 매개변수로 전달된 변수는 함수 내부에서만 유효하며 함수 종료 시 소멸한다.
  • 전역 변수 (Global Variable): 함수 외부에서 선언된 변수로 프로그램 전체에서 읽을 수 있다.
pressure = 103.9  # 전역 변수

def adjust(t):
    temperature = t * 1.43 / pressure  # t, temperature는 지역 변수
    return temperature

print(adjust(20))
# print(temperature)  # NameError: name 'temperature' is not defined

에러 트레이스백(Traceback) 분석 요령

  1. 마지막 줄 확인: 에러의 최종 유형과 원인 설명 (예: NameError: name 'x' is not defined)
  2. 발생 위치 추적: 파일명, 줄 번호, 에러가 발생한 구문 확인
  3. 호출 스택 파악: 함수가 중첩 호출된 경로를 역추적하여 최초 발화 지점 파악

clip(120)은 100을 정상 출력한다. 하지만 주석을 해제하고 print(value)를 실행하면 NameError가 발생한다. value는 clip 함수의 지역 매개변수이기 때문에 함수 외부에서는 존재하지 않는다.

Note핵심 요약
  • 함수 내부에서 정의된 변수는 지역 범위를 갖는다.
  • 함수 외부에서 지역 변수에 직접 접근하면 NameError가 발생한다.
  • 트레이스백 메시지의 마지막 줄부터 역순으로 추적하여 오류를 진단한다.

코딩 스타일의 중요성과 PEP 8

코드는 작성되는 시간보다 읽히는 시간이 훨씬 길다. PEP 8은 파이썬 공식 코딩 스타일 가이드이다.

  • 들여쓰기: 탭 대신 공백(스페이스) 4칸 사용
  • 변수 및 함수명: 소문자와 밑줄 사용 (snake_case)
  • 연산자 주변 공백: a = b + 1과 같이 연산자 앞뒤로 한 칸 공백 배치
  • 도구 활용: black, flake8, ruff 등의 린터/포매터를 사용하여 일관성을 자동 검증

단언문 (assert)을 활용한 사전 조건 검증

  • 코드 실행 중 반드시 만족해야 하는 가정을 점검할 때 assert를 사용한다. 조건이 거짓이면 AssertionError가 발생한다.
def calc_bulk_density(mass, volume):
    """질량과 부피로 벌크 밀도를 계산한다."""
    assert volume > 0, "부피는 반드시 양수여야 합니다."
    return mass / volume

def average(values):
    """숫자 리스트의 평균을 계산하여 반환한다.
    
    인수:
        values (list): 숫자 원소를 가진 리스트
    반환:
        float: 산술 평균값 (빈 리스트인 경우 None)
    """
    if len(values) == 0:
        return None
    return sum(values) / len(values)

def transform_string(input_str, steps=10):
    """인접 문자의 일치 여부에 따라 문자열을 변형하는 1차원 셀룰러 오토마타 시뮬레이션."""
