# Biopython을 이용한 심화 생명정보학 분석

## 1. 서론: 파이썬과 생명정보학의 결합

생명정보학(Bioinformatics)은 현대 생물학 연구의 중심에 있다. 수조 개의 염기서열 데이터가 쏟아지는 유전체학 시대에 데이터를 수동으로 처리하기란 불가능에 가깝다. 파이썬은 간결한 문법과 강력한 과학 계산 생태계를 바탕으로 생명정보학자에게 가장 널리 쓰이는 도구가 되었다.

그 중심에는 Biopython 프로젝트가 있다. Biopython은 단순히 파일을 읽고 쓰는 라이브러리를 넘어, 생물학적 서열을 수학적·컴퓨터공학적 객체로 다루고 외부 알고리즘(BLAST, ClustalW 등)과 연동할 수 있는 거대한 프레임워크이다.

## 2. 서열 객체의 심화 이해

### 2. Seq 객체와 불변성

Biopython의 `Seq` 객체는 파이썬 문자열(string)과 마찬가지로 불변성(immutability)을 갖는다. 이는 데이터 무결성을 보장하기 위한 핵심 설계 원칙이다.

```python
from Bio.Seq import Seq

dna = Seq("ATGGCCATT")
try:
    dna[0] = "G"
except TypeError as e:
    print(f"오류 발생: {e}")
```

서열을 직접 수정해야 하는 경우(예: 특정 잔기 치환 또는 돌연변이 삽입)에는 `MutableSeq` 객체를 이용하거나 리스트 형태로 변환한 뒤 다시 `Seq` 객체로 재구성해야 한다.

### 2. 전사와 번역의 세부 옵션

Biopython에서는 번역할 때 유전 암호표(Genetic Code)를 따로 지정할 수 있다. 미토콘드리아 유전체나 특정 세균은 표준 암호표와 다른 암호표를 사용하기 때문이다.

```python
messenger_rna = Seq("AUGGCCAUUGUAAUGGGCCGCUGAAAGGGUGCCCGAUAG")
# 표준 번역
standard_protein = messenger_rna.translate()
# 척추동물 미토콘드리아 암호표(Table 2) 사용
mito_protein = messenger_rna.translate(table=2)

print(f"표준 번역 결과: {standard_protein}")
print(f"미토콘드리아 번역: {mito_protein}")
```

## 3. NCBI Entrez를 이용한 온라인 데이터 획득

생명정보학 연구의 출발점은 신뢰할 수 있는 데이터의 확보이다. `Bio.Entrez` 모듈을 이용하면 웹 브라우저를 거치지 않고도 NCBI 데이터베이스(GenBank, PubMed 등)에 프로그래밍 방식으로 접근하여 서열 정보를 손쉽게 수집할 수 있다.

### 3. 이메일 설정과 검색

NCBI는 자동화된 요청 시 반드시 이메일 주소를 명시하도록 요구한다.

```python
from Bio import Entrez, SeqIO

# 자신의 이메일 입력
Entrez.email = "your_email@example.com"

# GenBank에서 특정 유전자(예: 인슐린) 검색
handle = Entrez.esearch(db="nucleotide", term="Homo sapiens insulin[Gene] AND mRNA[Filter]", retmax=5)
record = Entrez.read(handle)
id_list = record["IdList"]
print(f"검색된 ID 목록: {id_list}")
```

### 3. 서열 정보 다운로드 및 확인

```python
# 첫 번째 ID의 전체 정보 가져오기
fetch_handle = Entrez.efetch(db="nucleotide", id=id_list[0], rettype="gb", retmode="text")
seq_record = SeqIO.read(fetch_handle, "genbank")
fetch_handle.close()

print(f"서열 이름: {seq_record.name}")
print(f"설명: {seq_record.description}")
print(f"서열 길이: {len(seq_record.seq)}")
```

### 4. Pairwise2를 이용한 전역 및 지역 정렬

Biopython의 `pairwise2` 모듈(최신 버전에서는 `Bio.Align` 권장)을 사용하면 점수 체계(scoring system)를 직접 정의하여 정렬할 수 있다.

```python
from Bio import pairwise2
from Bio.pairwise2 import format_alignment

seq1 = Seq("GACAGTAGAC")
seq2 = Seq("GCACTAGAC")

# 전역 정렬(Global Alignment) 수행
# 매치: 2점, 미스매치: -1점, 갭 생성: -2점, 갭 연장: -0.5점
alignments = pairwise2.align.globalms(seq1, seq2, 2, -1, -2, -0.5)

for a in alignments:
    print(format_alignment(*a))
```

## 7. 유전체 데이터 시각화

생명정보학에서는 데이터 분포를 한눈에 파악하는 작업이 중요하다. 파이썬의 `matplotlib`과 `seaborn`을 연동하면 전문 학술지 수준의 그래프를 작성할 수 있다.

### 7. 윈도우별 GC 함량 선 그래프 그리기

```python
import pandas as pd
import seaborn as sns

# 서열의 슬라이딩 윈도우 GC 함량 계산 예시
def calculate_gc_window(seq, window_size=100):
    res = []
    for i in range(0, len(seq) - window_size + 1, window_size):
        subseq = seq[i:i+window_size]
        gc = (subseq.count("G") + subseq.count("C")) / len(subseq)
        res.append(gc)
    return res

# 가상의 긴 서열 생성
long_seq = Seq("ATGC" * 1000)
gc_values = calculate_gc_window(long_seq)

# 시각화
plt.figure(figsize=(10, 5))
sns.lineplot(x=range(len(gc_values)), y=gc_values)
plt.title("GC Content Across Sequence Window")
plt.xlabel("Window Index")
plt.ylabel("GC Fraction")
plt.show()
```

## 8. 대용량 데이터 처리를 위한 팁

오늘날 차세대 염기서열 분석(NGS) 데이터의 크기는 수 기가바이트(GB)에 달한다. 파일을 메모리에 한꺼번에 적재하면 시스템 메모리 부족(OOM)으로 프로세스가 중단될 수 있다.

- 제너레이터(Generator) 활용: `SeqIO.parse()`는 데이터를 순차적으로 읽어오는 제너레이터이다. 메모리 절약을 위해 `list()`로 감싸지 않고 `for` 루프에서 직접 순회한다.
- 인덱싱(Indexing): 대용량 FASTA 파일에서 특정 서열만 신속히 검색할 때는 `SeqIO.index()`를 사용하여 딕셔너리 형태의 인덱스를 구축한다.

## 9. 결론 및 향후 과제

Biopython은 생명정보학 분석을 위한 핵심 도구이다. 다만 이 도구를 제대로 활용하려면 리스트 컴프리헨션, 데코레이터 등 파이썬 고급 문법과 NumPy, Pandas 같은 데이터 과학 라이브러리를 깊이 이해하고 있어야 한다.

이 장에서는 서열 획득, 서열 정렬, 3차원 단백질 구조 탐색의 기본 기법을 다루었다. 나아가 PyTorch나 TensorFlow 등 딥러닝 라이브러리와 연계하면 분석 범위를 단백질 접힘(Protein Folding) 예측과 같은 첨단 생명정보학 연구 과제로 넓힐 수 있다.
